# مَدار | MADAR

**إدارة الأفراد، وتنمية الأعمال.**

منصة عربية مستقلة لتجربة إدارة خدمات الموارد البشرية لعدة عملاء. المصدر خاص بمستودع `madar8/Madar` ولا يتصل بحسابات أو بيانات أي مشروع آخر.

## الإصدار الحالي: تجربة Netlify مؤقتة — 0.2.0

هذه نسخة تجريبية كاملة المسارات الأساسية: واجهة عربية + Netlify Functions + بيانات ومستندات محفوظة في Netlify Blobs خاصة بالموقع. ليست صفحة عرض ساكنة، ولا تستخدم localStorage لحفظ سجلات العمل، ولا تعتمد على ملفات مؤقتة داخل الوظيفة.

**حالة النشر:** الملفات جاهزة. لا يعتبر هذا المستودع دليلًا على نشر موقع؛ يحتاج النشر دخول صاحب المشروع بحساب Netlify مستقل ومراجعة خطة Free. عنوان الموقع الفعلي يؤخذ من نجاح النشر لدى Netlify.

[إعداد تجربة مدار على Netlify](https://app.netlify.com/start/deploy?repository=https://github.com/madar8/Madar)

راجع [دليل Netlify](docs/DEPLOY_NETLIFY.md). لا ترفع مجلد `web` وحده بـ Drag & Drop، لأنه لا يشغل وظائف الخادم.

## حدود التجربة

| البند | الحد |
|---|---|
| الحسابات | 50 مستخدمًا |
| السجلات التشغيلية | 2000 سجل إجمالًا |
| حالة مساحة العمل | حتى 4 MiB JSON |
| المستند الواحد | 2 MiB، بصيغ PDF/PNG/JPG فقط |
| مجموع المستندات | 20 MiB |
| سجل التدقيق | يحتفظ بآخر 1000 عملية، يعرض آخر 500 |
| ملف نقل شامل | المستندات ضمنه حتى مجموع 3 MiB؛ للأكبر تنزل المستندات منفردة مع JSON |
| الجلسة | 8 ساعات، وإلغاء عند تغيير كلمة المرور أو تعطيل الحساب |
| الخطة | Netlify Free، ضمن رصيد وحدود المزود؛ ليست استضافة غير محدودة |

لا يوجد تفعيل لخطة مدفوعة أو شحن تلقائي في الكود. الوصول لحدود المزود قد يوقف الموقع حتى تجدد الحصة. الرصيد والميزات الفعلية يؤخذان من لوحة حساب Netlify، لا من تقديرات ثابتة هنا. قد توجد بداية باردة لوظائف الخادم؛ لا توجد مطالبة بإلغاء جميع أشكال التأخير.

التخزين الموحد ذو الكتابة الشرطية مصمم لتجربة صغيرة. عند تعديل متزامن يرجع 409 ويطلب التحديث بدل فقدان التعديل أو تنفيذ الموافقة مرتين. هذا لا يهدف لتشغيل SaaS كبير؛ عند التوسع انقل البيانات لقاعدة علائقية مناسبة أو استخدم مسار الاستضافة الدائمة.

## ما يمكن تجربته

| القسم | السلوك المنفذ |
|---|---|
| العملاء | إضافة وتعديل شركة، قطاع ومسؤول تواصل وخدمة، حالة نشط/موقوف |
| الموظفون | ملفات وأقسام ومسميات وتواريخ ورواتب وأرصدة إجازة |
| التوظيف | وظائف وشواغر ومرشحون ومراحل يدوية |
| الطلبات | تقديم إجازة أو طلب عام أو خطاب، موافقة/رفض، منع تداخل الإجازات وخصم الرصيد مرة واحدة |
| الحضور | تسجيل حضور وانصراف بوقت الخادم، سجل واحد يوميًا |
| الرواتب | مسير شهري فريد، حساب بالهللة، لقطة ثابتة، فصل الإعداد عن الاعتماد، كشف موظف معتمد |
| العقود والمستندات | سجلات عقود، تواريخ انتهاء، رفع وتنزيل محمي للملفات |
| الخدمات والمالية | تذاكر، أولوية وحالة، فواتير داخلية ومبلغ وضريبة يدخلها المستخدم |
| التقارير | إحصاءات فعلية، بحث وتصفية حسب الشركة، CSV، طباعة، JSON وملف نقل |
| الحسابات | مالك وHR وعميل وموظف، إنشاء وتعطيل وإعادة تعيين كلمة مرور وإلغاء جلسات |
| المتابعة | تنبيهات العقود والمستندات المنتهية أو القريبة، سجل تدقيق |

واجهة RTL تتكيف مع الجوال. قاعدة الصلاحيات تطبق في الخادم، لا في إخفاء الأزرار فقط. العميل مقيد بشركته، والموظف بملفه وطلباته ووثائقه ومسيراته المعتمدة. مزود الخدمة (المالك وHR) يرى شركاته وفق مصفوفة الصلاحيات في [SECURITY](docs/SECURITY.md).

## رحلة تجربة سريعة

1. انشر المستودع بحساب Netlify مستقل وخطة Free.
2. ضع رمزًا عشوائيًا خاصًا لا يقل عن 32 حرفًا في `MADAR_SETUP_TOKEN` ضمن متغيرات Netlify، بنطاق Builds وFunctions. لا ترسله في محادثة أو تضعه في GitHub.
3. افتح الرابط الذي يعيده Netlify بعد نجاح النشر. شاشة التأسيس متاحة مرة واحدة فقط عند عدم وجود مستخدم.
4. أدخل رمز التأسيس في مدار نفسه مع اسمك وبريدك وكلمة مرور جديدة من 12 حرفًا على الأقل.
5. سجل الدخول. يمكنك تحميل أمثلة وهمية من الزر الظاهر للمالك قبل إضافة أي سجل، أو إضافة شركة وموظفين حقيقيين للاختبار بحسب مراجعتك لبيئة التجربة.
6. أنشئ مستخدم عميل مرتبطًا بالشركة، ومستخدم موظف مرتبطًا بملفه، وجرب تقديم طلب ثم الموافقة من حساب آخر.
7. لإنشاء مسير: أدخله بحساب HR ثم اعتمده من المالك أو مسؤول العميل؛ معد المسير لا يعتمد مسيره.
8. عند الانتهاء صدّر البيانات والمستندات من الإعدادات. لا تعتمد على بقاء التجربة وحدها كنسخة احتياطية.

الأمثلة وهمية وتضاف فقط بأمر المالك على مساحة فارغة. لا توجد كلمة مرور افتراضية أو بيانات عرض ثابتة في التشغيل العادي.

## النقل لاحقًا

من «الإعدادات» استخدم تصدير JSON، وملف النقل مع المستندات إن كان ضمن الحجم. عند تجاوز حد الملف الشامل نزّل المستندات منفردة. بيانات التصدير لا تتضمن كلمات المرور أو الجلسات؛ عند النقل تعيّن كلمات مرور جديدة للحسابات.

نسخة Node نفسها قابلة للتشغيل على جهاز أو VPS بملفات دائمة، دون إعادة كتابة قواعد العمل. استيراد ملف النقل الكامل إلى مجلد جديد:

```bash
# ضع كلمة مرور جديدة خاصة للمالك في البيئة المحلية، وليس في المصدر.
export MADAR_IMPORT_PASSWORD='<NEW_PRIVATE_OWNER_PASSWORD>'
node scripts/import-transfer.mjs madar-transfer.json /srv/madar/trial-data owner@example.com
export MADAR_TRIAL_DATA_DIR=/srv/madar/trial-data
export MADAR_SETUP_TOKEN='<PRIVATE_RANDOM_32_PLUS_CHARACTER_VALUE>'
npm start
```

شغّل هذا المسار في **عملية Node واحدة فقط**؛ مخزن الملفات المحلي ليس قاعدة متعددة العمليات. الخادم المحلي على 127.0.0.1:8000. يحتاج HTTPS ووكيلًا مناسبًا عند عرضه خارجيًا، و`MADAR_SECURE_COOKIE=1`. المستخدمون المستوردون غير المالك يبقون معطلين حتى يعيد المالك تعيين كلمات مرورهم من الواجهة. [دليل النقل](docs/DEPLOY_NETLIFY.md#النقل-والنسخ).

## التشغيل المحلي

المطلوب Node.js 24:

```bash
npm ci
export MADAR_SETUP_TOKEN='<PRIVATE_RANDOM_32_PLUS_CHARACTER_VALUE>'
npm start
```

PowerShell:

```powershell
npm ci
$env:MADAR_SETUP_TOKEN = '<PRIVATE_RANDOM_32_PLUS_CHARACTER_VALUE>'
npm start
```

يستخدم التشغيل المحلي `.trial-data`، المحجوب من Git. Netlify يستخدم مخازن خاصة بالموقع لا تتبدل مع كل إصدار. لا تنقل ملفات بيانات أو أسرار إلى المستودع العام.

## مسار Python السابق

يبقى متاحًا للاستضافة الدائمة أو التطوير:

```bash
python server.py init --email owner@example.com --name "مدير مدار"
python server.py
```

هذا المسار يستخدم SQLite ومجلد `data` محليًا. `wsgi.py` وGunicorn وDocker للتهيئة على خادم مناسب، ولا يشغلها Netlify. بيانات مسار Python منفصلة عن تجربة Node حتى تنفذ عملية ترحيل صريحة. أداة `backup.py` تخص مسار Python فقط. لا تنطبق حدود التخزين التجريبية نفسها على SQLite، لكن واجهة رفع الملفات موحدة على 2 MiB في هذا الإصدار.

اجتاز الإصدار عند الإنشاء اختبارات محلية خاصة بمسار Node تشمل الأدوار والعزل والتزامن وحفظ الحالة وإعادة إنشاء الوظيفة والمستندات والتصدير. توجد أيضًا 34 تجربة HTTP/WSGI لمسار Python. هذه ليست شهادة اختبار اختراق أو حمل أو إثبات نشر Netlify. النشر الفعلي يراجع من لوحة الخدمة ثم يختبر الدخول والحفظ بعد إعادة التحميل والتنزيل المحمي.

## ملفات مهمة

- `trial/core.mjs`: المصادقة والصلاحيات وقواعد العمل لتجربة Netlify.
- `netlify/functions/api.mjs`: واجهة وظائف Netlify مع مخازن خاصة وقراءات قوية.
- `netlify.toml`: إعداد النشر والأمان.
- `trial/file-store.mjs` و`trial/local.mjs`: تشغيل نفس API خارج Netlify.
- `scripts/import-transfer.mjs`: استيراد آمن إلى مساحة فارغة مع تغيير كلمات المرور.
- `web/`: الواجهة العربية المشتركة.
- `server.py` و`wsgi.py`: المسار الأصلي Python/SQLite للاستضافة الدائمة.
- `docs/PRODUCT.md`: نطاق التنفيذ والأعمال التجارية المتبقية.
- `docs/SECURITY.md`: الصلاحيات وحدود الحماية.

## حدود وظيفية مهمة

الإجازة أيام تقويمية شاملة البداية والنهاية. صافي الراتب = الأساسي + البدلات − الخصومات المسجلة؛ لا يحسب التأمينات أو الاستحقاق الجزئي أو نهاية الخدمة تلقائيًا ولا يحول أموالًا. العقود بيانات داخلية دون توقيع إلكتروني، والفواتير سجلات وليست فوترة ضريبية معتمدة. الحضور لا يثبت الموقع أو البصمة. لا توجد خدمة دفع أو بنك أو منصة حكومية أو بريد أو AI مرتبطة. لا توجد شهادة ISO/SOC أو ادعاء جاهزية تجارية نهائية.
