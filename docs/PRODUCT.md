# مواصفات المنتج وخريطة الإكمال

## الغرض

مدار يدعم شركة تقدم خدمات موارد بشرية خارجية لعملاء متعددين. الواجهة موحدة للمزود، مع بوابة مقيدة للعميل وبوابة للموظف. الاسم والواجهة والمصدر مستقلون؛ لا تنسخ علامات أو محتوى أو شيفرة شركات أخرى.

## نموذج البيانات الحالي

المستخدم: هوية، اسم، بريد فريد، ملخص كلمة المرور، دور، شركة اختيارية، ملف موظف اختياري، حالة. الجلسة مرتبطة بالمستخدم ومحددة المدة.

سجل العميل مستقل وله معرف. جميع سجلات الموظفين والوظائف والمرشحين والطلبات والعقود والحضور والرواتب والمستندات والتذاكر والفواتير تحمل company_id. العلاقات مثل مرشح ← وظيفة أو عقد ← موظف تتحقق من تطابق الشركة على الخادم. الموظف يربط بحساب دخول منفصل. مسير الرواتب يخزن لقطة مستقلة لكل موظف. سجل التدقيق منفصل عن البيانات التشغيلية.

يستخدم الإصدار الحالي جدول سجلات JSON مفهرسًا لكل قسم، مع قيود فريدة للحضور والمسير. عند التوسع المطلوب جداول علائقية لكل مجال ومفاتيح مرجعية وترحيلات مرقمة؛ لا تعدل بيانات الإنتاج مباشرة دون خطة ترحيل.

## المرحلة الحالية: تشغيل أساسي (مطبقة)

الأقسام والقواعد المطبقة مفصلة في README. المسارات الأساسية تعمل خلف جلسة وصلاحيات فعلية. يستطيع المستخدم تجربة شركة وموظف وطلب وموافقة ومسير ومستند وتصدير. لا توجد سجلات أو إحصاءات وهمية بعد التشغيل العادي؛ البيانات التجريبية منفصلة وتُنشأ بأمر صريح.

## المرحلة التالية: استكمال التشغيل التجاري (غير منفذة)

| المجال | التفاصيل المطلوب تنفيذها ومعايير القبول |
|---|---|
| التهيئة | معالج تأسيس شركة، فروع وأقسام ومراكز تكلفة، استيراد CSV بمعاينة أخطاء، منع التكرار وخريطة حقول |
| التوظيف | طلب احتياج وموافقة، لوحة مراحل بالسحب، مقابلات وجدولة، تقييمات يدوية موثقة، خطاب عرض، تحويل المرشح لموظف، حفظ الموافقات |
| التهيئة والمغادرة | قوائم مهام ومسؤول وموعد، عهد، تجربة، تقييم، تسليم واستعادة عهد، إخلاء طرف وإلغاء وصول |
| الإجازات | سياسات حسب الشركة والعقد، أنواع وأرصدة وتراكم، دوام وعطل، نصف يوم، إلغاء معتمد يعيد الرصيد بمعاملة، تفويض وموافقات متعددة |
| الحضور | شفتات، جداول عمل، طلب تصحيح، تأخير وإضافي، تكامل أجهزة أو تطبيق تحقق موقع بموافقة واضحة؛ لا يفرض مراقبة غير ضرورية |
| الرواتب | متغيرات شهرية ومراجعة ومدخلات استيراد، فترات جزئية، مستحقات وسلف وقروض وخصومات، قواعد مؤرخة ومحرك احتساب قابل للتحقق، كشوف رسمية، تسويات وإقفال وعكس موثق |
| العقود | قوالب مؤرخة، نسخ وتعديلات وتجديد وإشعارات، اختيار مزود توقيع رسمي وحفظ أدلة التوقيع |
| المستندات | ربط بعقد، تصنيف وحساسية ومدة احتفاظ، مراجعة ونسخ، فحص ملفات، سياسات وصول أدق وتنبيه خارجي |
| علاقات العملاء | عروض خدمات وموافقات، اتفاقية SLA، مالك حساب، زمن أول استجابة وحل، تصعيد وساعات عمل، تعليقات ومرفقات على التذاكر |
| المالية | كتالوج باقات، عقود خدمات واشتراكات، استحقاق وتحويل عملات عند الحاجة، إشعارات دفع، فواتير ضريبية عبر مزود مؤهل، قيود محاسبية وتسويات |
| الأداء | أهداف ودورات مراجعة وتعليقات وتقييمات بشرية، تطوير وتدريب وشهادات، دون قرارات توظيف آلية غير مراجعة |
| الإشعارات | قوالب عربية وإنجليزية، تفضيلات، سجل إرسال، طابور ومحاولات وإلغاء اشتراك مناسب؛ مزود منفصل لحساب مدار |
| المنصة | لغة إنجليزية، إمكانية وصول وفق اختبارات WCAG، توثيق API بإصدارات، pagination على الخادم، فلاتر متقدمة، saved views، مهام مجدولة |

## الأمان والاعتماد (غير مكتمل)

تفاصيل المتبقي في SECURITY. يلزم اختبار اختراق وتحمل ومراجعة امتثال وسياسات حقيقية قبل ادعاء اعتماد دولي. جودة النظام تقاس بسلوك واختبارات وأدلة تشغيل؛ لا يمكن تأكيد أنه «أفضل» من منافس دون مقارنة عملية موثقة.

## التكاملات المطلوبة من أصحاب الحسابات

الحسابات المستقلة تشمل مستودع GitHub، استضافة مع قرص دائم، دومين وDNS، إرسال رسائل، نسخ احتياطي مشفر، ثم مزودي توقيع ودفع وبنوك ومنصات حكومية عند الترخيص والتوافر. لا تُنشأ حسابات مالية أو تُقبل اتفاقيات نيابة عن المستخدم ضمن هذا الإصدار.

كل تكامل يحتاج: صاحب الحساب، النطاق/البيئة، وثائق المزود، موافقة الصلاحيات، مفاتيح محفوظة في مدير أسرار، اختبار sandbox، تحديد webhooks وتوقيعها ومنع replay، سجل طلبات غير حساس، سيناريو فشل واسترداد، ومسؤول دعم. لا يكفي عرض شعار المزود لإثبات الاتصال.

## معيار تسليم الإصدار التالي

- اكتمال رحلة استخدام لكل دور دون أزرار لا تعمل أو بيانات عرض ثابتة.
- اختبارات عزل العميل والموظف لكل endpoint جديد، واختبارات حسابات مالية وعكس المعاملات.
- اختبار قبول من صاحب المشروع على بيانات وهمية ثم عميل تجريبي واحد.
- تشغيل نسخ احتياطي واستعادة ومراقبة قبل إضافة بيانات حقيقية.
- توثيق واضح لما يدعمه الإصدار وما يحتاج حسابًا أو ترخيصًا خارجيًا.
